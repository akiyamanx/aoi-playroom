# ここちゃんの こし（骨盤） pelvis-v1.1

約70 cm・二足歩行めざしの ここちゃんロボット。こし（骨盤）と足のつけね3軸×左右です。**寸法・質量はぜんぶ仮（PLACEHOLDER）**。

## v1.1 で変えたこと
1. **胴を30 mm低く**：背骨フレーム 260→230 mm、肩の軸 250→220 mm（腕も一緒に下へ）。胸の中のサーボ・頭脳ベイ・IMU も30 mm下げました。
2. **バッテリーを腰プレートのすぐ上へ**：うすいトレイ（底2 mm・ふち8 mm）＋**ベルト2本でしばる**方式（仮）。床の高さ 35→2 mm。背骨の柱とぶつからないよう、**背骨のうしろ（X=−35 mm）**に置きました。
3. **足の前後モーター（AK45-10クラス）を骨盤の左右の外側へ**。軸は人の股関節と同じく左右向き（Y軸）。骨盤ブロックは幅110 mm（±55）、前後モーターは |Y| = 57.5〜102.5 mm で外側です。
4. 順番は人と同じ **ひねり → 横ひらき → 前後**。**3つの軸は1点（股関節の中心）で交わります**（ひねり軸 X=0,Y=±80 の縦線／横ひらき軸 Y=±80,Z=-175.0 の前後線／前後軸 X=0,Z=-175.0 の左右線）。横ひらきモーターの本体は軸の上で52 mm後ろにずらしてあるだけで、軸のずれは0 mm です（v1 の説明「50 mmずれ」は本体位置のことで、軸は v1 でも交わっていました）。
5. 足どうし・部品どうしの干渉チェック（STEP同士の重なり体積）を、ふつう／前後 +90°・−30°／横ひらき +30°・−20°／ひねり±30°との組み合わせで実施 → **重なりなし**（`collide.py`）。

## こしと足のつけね
- **こしひねり**：STS3215（45×25×35 mm・55 g 仮）。腰プレートの左右パッド（M3×4、PCD32）にアダプタを留め、曲げは薄型ベアリング（72/52×7 mm・45 g 仮）で受けます。
- **足のつけね（左右）**
  1. **ひねり（hip yaw, Z軸）**：STS3215。骨盤の下の「つばさ板」（幅200 mm）にぶら下げ。**股関節で脚まるごとを縦の軸で回す**動き（つま先を内・外に向ける、歩きながら向きを変える）。
  2. **横ひらき（hip roll, X軸）**：AK45-10クラス（Ø53×45 mm・260 g 仮）。軸の後ろ側に本体。
  3. **前後（hip pitch, Y軸）**：AK45-10クラス。骨盤の外側。ももの板が両面ではさむ。
- 太ももは上の部分だけ（スタブ）。

## 気になるところ（OPEN ISSUES）
1. 寸法・質量はデータシート未確認の仮。AK45-10 の実寸・取付ピッチを要確認。
2. バッテリー（幅155 mm）は腰プレート（幅120×奥90 mm）よりはみ出し、背骨の後ろに置いたので後ろに約16 mm はみ出します。トレイの支えを追加するか、パックの形を見直す必要あり。
3. バッテリーを後ろに置いたので重心が少し後ろ（X≈-5.6 mm）。
4. 骨盤の左右の外側にモーターが出たので、股のはば（前後モーター外端）が約 ±103 mm。肩（±100 mm）と同じくらいです。
5. STS3215 の腰ひねり・股のひねりはトルク余裕が少ないかも（減速・ベアリング検討）。
6. 胸のカバー・肩の穴・ボーデンの長さは自動で30 mm下がっただけで、細かい見直しはまだ。
7. URDF の慣性テンソルはダミー（質量と重心だけ有効）。脚（ひざ下）が未設計なので、地面からの重心の高さはまだ出せません。
