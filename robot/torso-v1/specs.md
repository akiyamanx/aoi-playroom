# ここちゃんの「からだ」中身 v1

二足歩行をにらんだ、約70 cmヒューマノイド（ここちゃんロボット）の**胴体の中身レイアウト**です。腕は [arm-v5](../arm-v5/) を左右に取り付けています。指のサーボは前うでから胴体へ移し、**ボーデンケーブル（PTFEチューブ＋PEライン／細いステンレス）**で指を動かします。

参考イメージ：HighTorque Mini Pi Plus（約68 cm / 15.4 kg / 22 DOF）。ここちゃんは目標身長約70 cm。

## レイアウト方針（歩くために）

重いものを**低く・中央・骨盤の近く**に置きます。

| もの | 置き場所 | なぜ |
|---|---|---|
| バッテリー | 腰のすぐ上・まんなか・取りはずし可 | いちばん重い。重心を下げる |
| 指サーボ＋テンショナー | 胸の左右に5こずつ | 腕を軽くする。左右対称 |
| コントローラー＋ドライバ＋IMU | 胴の中央。IMUは重心の近く | 配線短く、姿勢センサがCoM付近 |
| 肩モーター（AK45-10 仮） | 胴の上・外側 | 腕の付け根 |
| 骨格 | 背骨フレーム＋腰プレート＋外カバー | あとから部品を動かせる。脚は腰プレートに付ける予定 |

## 指の駆動（胴体側）

- サーボは片手5こ・合計10こ（マイクロサーボ、**仮寸法** 12.2×23×29 mm・約11 g）。
- 各指は**プッシュプルのループ**：ワイヤがサーボプーリーを1周し、手のひら側と甲側の両方へ行くので、1サーボで曲げ伸ばし。
- 各ループに**ばね入りテンショナー**（Vベルトテンショナーみたいなアイドラ）。ネジで張り調整。
- **形状記憶合金は使わない**。
- にぎる力の制御はソフトで：まずトルク制限で閉じ、接触したらトルクを上げる（予定）。

## 座標系

- 原点：腰プレート上面の中心
- **+Z**：上（頭のほう）
- **+Y**：ロボットの左
- **+X**：前

肩ピッチ軸の位置：Y = ±100 mm、Z = 250 mm。

## この版の限界（LIMITATIONS）

1. すべてのモーター寸法・質量は**データシート未確認の仮**です。
2. 腕の重心は肩からの概算ボックスで、関節角度つきの厳密なFKではありません（腕は下ろした姿勢の目安）。
3. あたまは中身の詰まった仮球体で重いです。あとでくり抜きます。
4. カバーは簡易シェルで、ネジ位置・防水・メンテ開口は未設計です。
5. 脚・腰モーターは未実装（取り付け座だけ）。
6. ボーデンの実長さ・摩擦・最小曲げ半径は未検証です。
7. 肩ブラケットと腕カップの接合はビジュアル接続で、ボルトパターンの実合わせはこれから。
